# Week 7 - Complete Pack (DN 5.0 Java FSE Angular)

The original `Week 7` folder in the GitHub repo only contained the Angular
capstone project (`student-course-portal`). Per the Deep Skilling Handbook,
Week 7 is meant to close out the **"Products & Frameworks"** construct
(Angular + Debugging) and the entire **"Platforms & GenAI"** construct
(Git, DevOps/CI-CD, Docker, Agile, Cloud Fundamentals, GenAI Fundamentals).

This pack fills in every module that had no downloadable hands-on content
in the repo, so you have something concrete to *do* for each topic instead
of just reading links and taking a quiz.

| Folder | Handbook Module | What's inside |
|---|---|---|
| `Module 09 - Angular` | Module 9 | The original `student-course-portal` Angular app (unchanged) |
| `Module 10 - Application Debugging` | Module 10 | A bug-hunt exercise: 5 intentionally-broken behaviors in the Angular app for you to find using Chrome DevTools / VS Code debugger |
| `Module 12 - DevOps and CICD` | Module 12 | A working GitHub Actions CI pipeline you can drop into any repo, plus a hands-on exercise |
| `Module 13 - Docker` | Module 13 | Dockerfiles for a Spring Boot backend + the Angular frontend, a docker-compose.yml, and a step-by-step lab |
| `Module 14 - Agile Methodology` | Module 14 | A user-story / acceptance-criteria / sprint-planning template exercise, applied to the course portal app |
| `Module 15 - Cloud Fundamentals` | Module 15 | An AWS console walkthrough lab (EC2, S3, RDS, Lambda, API Gateway) with checklists |
| `Module 16 - GenAI Fundamentals` | Module 16 | Prompt engineering exercises + a GitHub Copilot hands-on task list |

**Note on Git (Module 11):** that hands-on already exists in your repo under
`Week 6`, so it isn't duplicated here.

## Suggested order
1. Finish/verify `Module 09 - Angular` (if not already done)
2. `Module 10 - Application Debugging`
3. `Module 12 - DevOps and CICD`
4. `Module 13 - Docker`
5. `Module 14 - Agile Methodology`
6. `Module 15 - Cloud Fundamentals`
7. `Module 16 - GenAI Fundamentals`

Each folder has its own `*_EXERCISE.md` (or README) with step-by-step
instructions and a "Self-Evaluation" checklist, matching the format used
in the rest of the DN 5.0 hands-on repo.

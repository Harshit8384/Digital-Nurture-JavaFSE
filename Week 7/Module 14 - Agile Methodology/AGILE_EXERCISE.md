# Module 14 - Agile Methodology Exercise

No hands-on file exists for this module in the repo either — just links
and a SkillSpring course. This exercise applies Agile concepts to the
`student-course-portal` app you already built, so it's concrete instead
of abstract.

## Learning objectives covered
- Write user stories using the standard format
- Apply the INVEST principle
- Define acceptance criteria using Given-When-Then
- Practice story-point estimation and sprint planning

## Part A - Write 5 user stories
Using the format:
> As a [user role], I want [goal], so that [benefit]

Write 5 user stories for **features the course portal app doesn't have
yet** — pick from ideas like: filtering courses by category, a "my
enrolled courses" dashboard, email notification on enrollment,
pagination on the course list, or a course rating/review feature.

For each story, check it against **INVEST**:
- Independent
- Negotiable
- Valuable
- Estimable
- Small
- Testable

## Part B - Acceptance criteria
For **2 of your 5 stories**, write acceptance criteria in
Given-When-Then format. Example:
```
Given I am on the course list page
When I select "Programming" from the category filter
Then only courses in the "Programming" category are displayed
```
Write at least 2 Given-When-Then criteria per story (happy path + one
edge case, e.g. "no courses match the filter").

## Part C - Estimate and plan a sprint
1. Assign story points (use the Fibonacci-like scale: 1, 2, 3, 5, 8, 13)
   to all 5 stories, using Planning Poker reasoning (relative sizing vs.
   each other, not hours).
2. Assume your team's velocity is 10 points per sprint. Decide which
   stories fit into "Sprint 1" and which get pushed to "Sprint 2".
3. Write a one-paragraph Sprint Goal for Sprint 1.

## Part D - Reflection (`AGILE_NOTES.md`)
1. Which Scrum ceremony would you use to review Sprint 1's stories with
   the team, and which would you use to decide Sprint 2's stories?
2. What's the difference between a Product Backlog and a Sprint Backlog
   in your own words?
3. Pick one story that felt hard to estimate — why?

## Deliverable
Fill in `AGILE_BACKLOG_TEMPLATE.md` with your 5 stories, acceptance
criteria for 2 of them, story points, and sprint assignment.
